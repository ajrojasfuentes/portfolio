- Architected and developed a comprehensive full-stack **ERP web platform** for the third sector (NGO), centralizing administrative, financial, and medical operations into a single system.
- Built a **Beneficiary Management System (BMS)** with an integrated **Electronic Health Record (EHR)** subsystem, enforcing strict Role-Based Access Control (RBAC) to safeguard sensitive patient data.
- Developed a **Financial Management System (FMS)** featuring automated recurring billing and subscription workflows, alongside a Procurement Management System (PMS) and Inventory Management System (IMS) for end-to-end resource tracking.
- Implemented an **Association Management System (AMS)** to support board governance, and a **Human Resources Information System (HRIS)** to manage staff lifecycles and shift scheduling.
- Unified all subsystems into a single ERP web platform, with automated data-sync workflows, an intuitive user interface, and centralized RBAC for consistent security across modules.
